# data/

- `raw/` (git-ignored): real catalogue files downloaded by hand from CelesTrak (CSV/OMM or TLE). Do not commit large files.
- Synthetic catalogues generated by the program/scripts (fixed seed) go in `data/synthetic/`.
- Record in this file where and when each real file was downloaded.

## Not in the repository
- `raw/` (CelesTrak files above) is git-ignored; download it again with the groups listed in the table.
- `history/` holds Space-Track element history used only to calibrate the age-aware distance (`scripts/fetch_spacetrack_history.py`, `scripts/calibrate_age_from_history.py`). Space-Track data requires a free login and its terms restrict redistribution, so it is git-ignored. Re-fetch it with your own account.
